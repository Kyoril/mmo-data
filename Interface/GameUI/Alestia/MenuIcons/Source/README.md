# Action bar menu icons

Generated warm-gold menu artwork, with original transparent PNGs retained alongside normalized 128 x 128 import sources. Each silhouette fits within 112 x 112 pixels. Imported as DXT5 HTEX with one mip using the project import_item_icon.py tool.

Character: helmet; Repertoire: spellbook; Emotes: speech bubble; Inventory: backpack; Quests: scroll; Talents: branching nodes; Menu: cog.

Used only for action-bar menu entry icons. Buttons display a centered 60 x 60 logical-pixel image within their existing 80 x 96 bounds.
